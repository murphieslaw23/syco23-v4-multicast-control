# Design Tokens — SYCO23 v4 Reference

Extracted from `syco23_multicast_control_app_redesign.html` and the v4.1 dark ash edition pack.

## Philosophy
Design tokens are codified brand constraints: the allowed materials, signals, and cadence of the interface.

## Materials
- Base surfaces: `#050506`, `#0b0a0d`, `#121115`, `#18161b`, `#070608`
- Borders/structures: `#232128`, `#1c1a20`, `#27252c`, `#312e38`
- Text: `#ded9e2` base, `#8a8194` secondary, `#6b7280` muted

## Signal Colors
- Rust orange
- Deep crimson
- Dull amber
- Oxidized copper
- Dirty turquoise
- Burnt ochre

## Typography
- Display: bold, condensed, industrial
- Body/UI: clean, readable
- Utility: monospace

## Motion
- Sparse, signal-like
- Glitch only as fault indicator or transmission state behavior
- No decorative animation

## Anti-patterns (Hard Prohibitions)
- Terminal/console aesthetic
- Neon rave graphics
- Cyberpunk chrome/glow
- Glossy gradient buttons/cards
- Bubbly rounded SaaS card soup
- Icon-in-colored-circle feature grids
- Centered-everything layouts
- Generic analytics dashboard structure
