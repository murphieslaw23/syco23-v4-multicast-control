# SYCO23 v4.1 — Design Layout Prompt

Design the SYCO23 ecosystem as **two primary UI projects** inside one shared brand system:

1. **syco23-webplayer** — public listening surface.
2. **syco23-transmission** — operator multistream control surface.

The supporting non-UI projects are **azuracast** on Linode VPS and **syco23bot + syco23adminbot** on Telegram. These supporting projects must still inherit the same tone, hierarchy, and information design language in dashboards, messages, alerts, and generated assets.

## Shared visual language

- Mechanical totem.
- Ancient visual energy.
- Large sound-system scale.
- Dark mineral surfaces.
- One dominant key color per screen or mode.
- Bold condensed industrial display type.
- Clean readable body text.
- Sparse signal-like motion only.

**Avoid** terminal aesthetics, neon rave art, cyberpunk, glossy startup visuals, soft bubbly cards, generic dashboard layouts, and decorative glitch.

## syco23-webplayer layout guidance

- Mobile portrait first.
- Full-screen immersive listening surface with stacked content hierarchy.
- Clear now-playing and live-state visibility.
- Strong fallback states for offline, reconnecting, and maintenance.
- Background art and overlays must never break readability.
- Future-ready slot for optional visual preview player.

## syco23-transmission layout guidance

- Desktop control surface must be scroll-free or nearly scroll-free in the primary live mode.
- Layout centered around a control spine with source state, master transmission state, and destination matrix.
- Providers appear as transmission nodes, not social media promo tiles.
- Secondary details live in drawers or adjacent panels.
- Template gallery must show meaningful generated preview images.
- Colorized log view must feel like telemetry, not chat or notification feed.
- Built stream preview player must look like a monitor window, not a generic browser video box.

## Telegram bot message guidance

- Bot replies must be direct, compact, and operational.
- Public bot messages should be clear and easy to scan.
- Admin bot alerts should prioritize state, error, and actionability.
- Messaging should reflect SYCO23 voice without sounding corporate or playful.

## Cross-project consistency

Design all surfaces so they feel like parts of the same machine: the public player, the transmission app, the backend/admin utilities, and the bots should all read as one ecosystem.
